# Spending Risk AI (AI 기반 과소비 위험 패턴 분석 및 소비 개선 리포트 시스템)

본 프로젝트는 대학 과제 제출 및 개인 재무 설계를 목적으로 개발된 **AI 기반 스마트 소비 패턴 진단 대시보드**입니다. 사용자의 고정 기준 지출 내역(2~4월)과 실시간 입력 지출 내역(5월)을 분석하고, 구글 Gemini API를 연동하여 초개인화된 개선 솔루션과 시각화 리포트를 생성합니다. 

이 프로젝트의 UI/UX 디자인 시스템은 프리미엄 핀테크 서비스의 감각을 살린 **Kinetic Ledger** 비주얼 시스템을 계승하여 설계되었습니다.

---

## 🚀 핵심 차별화 기능 및 특징

1. **Vite + React 기반의 고속 핀테크 대시보드 시각화**
   - **Recharts** 라이브러리를 사용해 월별 추이, 카테고리별 분해, 시간대별 및 요일별 소비 쏠림 현상을 다차원 분석 차트로 제공합니다.
   
2. **다이내믹 월별 진단 지원 (2월, 3월, 4월, 5월 및 비교)**
   - **2~4월 baseline 데이터**: 고정된 기준치 소비 정보로, 소비 패턴의 기본 행동 정립 기준이 됩니다.
   - **5월 실시간 CRUD 데이터**: 사용자가 직접 소비 내역을 추가/삭제할 수 있으며 브라우저의 `localStorage`를 통해 유지관리됩니다.
   - **5월 vs 최근 3개월 평균 비교**: 3개월간의 평균 지출 구조와 5월의 지출 패턴을 1:1 대응하여 이상 과소비 징후를 추적합니다.

3. **인터랙티브 경고 필터 및 "경고 관련 소비 내역" 모듈**
   - 대시보드의 "소비 유형", "과소비 위험 요인", "가장 위험한 소비 패턴" 등의 경고 요소를 클릭하면, 해당 위험 요인을 유발한 구체적인 소비 기록만 테이블에 **실시간으로 필터링**되어 나타납니다.
   - *예시*: "야간 배달형" 클릭 시 22시~06시 사이의 배달 카테고리 내역만 상세 조회.

4. **더욱 강력해진 Gemini 1.5 Flash AI 솔루션 및 "AI 개선안 추천"**
   - 구글 Gemini API를 활용하여 단순 요약이 아닌, 위험 등급 부여의 직접적인 증거(Evidence)와 수치(건수, 가맹점, 시간)를 짚어내는 초정밀 리포트를 제공합니다.
   - **AI 개선안 추천**:
     - 가장 먼저 대폭 줄여야 할 핵심 소비 & 안정적으로 유지해도 좋은 항목 구분
     - 카테고리별 한 달 권장 예산 한도 제안
     - 야간 지출 통제 전략 및 구독 서비스 다이어트 챌린지 룰 수립
     - 다음 달 지출 핵심 수칙 및 실천 체크리스트 제공
     
5. **보고서 캡처용 요약 (University Assignment Snapshot) 카드 제공**
   - 대학 레포트 및 프레젠테이션 과제 제출 스크린샷 캡처에 특화된 전용 요약 카드인 **"보고서용 요약"** 영역이 하단에 마련되어 있습니다. 한눈에 들어오는 시각화 템플릿 형태로 인쇄 및 스크린샷 캡처가 매우 용이합니다.

6. **완벽한 한국어 로컬라이징 및 견고한 Fallback 메커니즘**
   - 모든 UI 텍스트, 차트 라벨, 버튼, 리포트 결과물은 완벽하게 한국어로 고안되었습니다.
   - Gemini API 호출이 실패하거나 키가 설정되지 않은 경우에도 자체 통계 알고리즘에 기초한 고도화된 **한국어 기본 분석 리포트(Fallback)**가 작동하여 앱이 절대 크래시되지 않습니다.

## 🛠 기술 스택

- **Core**: React 19, TypeScript, Vite
- **UI Styling**: Vanilla CSS (Kinetic Ledger Refined Minimalism Theme 적용)
- **Data Visualization**: Recharts (3.x)
- **Icons**: Lucide React
- **Local Storage**: 데이터 및 분석 캐시 로컬 저장
- **LLM API**: Google Generative AI (Gemini 1.5 Flash 모델)

## 🎨 UI/UX 디자인 시스템 (Kinetic Ledger Reference)

본 프로젝트는 `stitch` 디자인 리소스의 **Kinetic Ledger** 템플릿 가이드라인을 엄격히 준수하여 디자인을 전면 개선하였습니다.
- **Color Scheme**: 짙은 신뢰감을 주는 딥 네이비(Deep Navy `#0F172A`)와 생동감 넘치는 액티브 블루(Vibrant Blue `#3B82F6`)를 주요 테마로 설정했으며, 긍정적인 지표에는 민트 그린(Mint Green `#10B981`), 경고성 지표에는 에러 레드(Error Red `#BA1A1A`)를 할당하여 정보의 인지 한계를 극복했습니다.
- **Canvas & Radii**: 전체 배경은 부드러운 오프화이트/슬레이트 그레이(Neutral Canvas `#f7f9fb`)를 사용하여 피로도를 낮추고, 개별 analytical card는 순수 화이트 `#ffffff`와 24px의 넓은 라운드값(`border-radius: 1.5rem`), 초경량 저대비 보더(`1px solid #ECEEF0`), 미세한 앰비언트 소프트 섀도우를 조합해 세련된 시각 레이어를 확립했습니다.
- **Forms & Inputs**: 입력란 높이를 48px로 확장하고 기본 상태의 외곽선을 제거해 미니멀리즘을 도모했으며, 포커스 시 부드러운 액티브 블루 보더와 은은한 발광 효과가 작동하는 정밀 마이크로 애니메이션을 제공합니다.

## ⚙️ 실행 및 연동 방법

### 1. 패키지 설치
프로젝트 폴더로 이동한 후 필요한 라이브러리를 동기화합니다.
```bash
npm install
```

### 2. 환경 변수 설정 (`.env.local` 또는 `.env`)
루트 경로에 `.env.local` 또는 `.env` 파일을 생성하고 발급받은 구글 제미나이 API 키를 설정합니다.
```env
VITE_GEMINI_API_KEY=
```
*(참고: 이미 키가 등록되어 있으므로 즉시 구동 가능하며, API 키가 유효하지 않거나 없어도 Fallback 기능이 매끄럽게 작동합니다.)*

### 3. 개발 서버 실행
```bash
npm run dev
```

### 4. 브라우저 접속
서버 기동 후 안내되는 로컬호스트 URL(예: [http://localhost:5173/](http://localhost:5173/))로 접속하여 대시보드를 자유롭게 조작합니다.

## 📊 위험도 산출 점수 공식 (Risk Score Logic)

위험 점수는 다음과 같은 7대 감점 요인에 근거하여 0점부터 100점까지 산출됩니다.

1. **비필수 소비 비중 (최대 25점)**: 배달, 카페, 쇼핑, 문화 지출이 전체 소비의 60% 이상이면 25점 감점
2. **야간 결제 비율 (최대 20점)**: 22시~06시 사이 지출 비중이 25% 이상 시 20점 감점
3. **지출 쏠림 현상 (최대 25점)**: 단일 지점에 30% 이상 쏠림 시 15점, 특정 가맹점 4회 이상 중복 결제 시 10점 감점
4. **구독 요금 과다 (최대 15점)**: 정기 결제 및 고정 구독 비율이 15% 이상 시 15점 감점
5. **고액 결제 빈도 (최대 15점)**: 5만 원 이상 일시불 결제가 3회 이상 발생 시 15점 감점
6. **소액 결제 남발 (최대 10점)**: 1만 원 미만의 결제가 10회 이상 누적 시 10점 감점
7. **전월 대비 지출 폭등 (최대 30점)**: 5월 한정으로 전월 3개월 평균치보다 총지출이 20% 늘거나, 야간 소비 및 비필수 항목 지출이 30% 급격히 증가한 경우 각 항목별로 감점 적용
